# 다함께 차차차 (웹 버전)

브라우저에서 바로 즐기는 차선 변경 레이싱 게임입니다. HTML 파일 하나로 되어 있고, 외부 라이브러리나 이미지 없이 Canvas로 그립니다.

**플레이:** https://taemin2000min-debug.github.io/chachacha/

## 조작법
- **키보드:** ← → 또는 A / D 로 차선 변경, Esc / P 로 일시정지
- **모바일:** 화면 왼쪽·오른쪽 터치 또는 스와이프

## 규칙
- 앞차와 부딪히면 게임 오버
- 연료가 계속 줄어들어요. 빨간 연료통(F)을 먹어서 채우세요
- 코인: +10점
- 부스터(N): 3초 동안 무적이 되고 빨라져요. 부딪힌 차는 날아가요 (+50)
- 옆 차선 차를 아슬아슬하게 지나가면 +20

## 로컬 실행
`index.html` 을 브라우저로 열면 됩니다.
